# Drishti Landing Page

Premium static pitch page for Drishti, an AI-powered vision augmentation system.

## View Locally

Open `index.html` directly in a browser, or run:

```bash
npm install
npm run preview
```

## Deploy

This is a plain static site. Deploy the project root to GitHub Pages, Netlify, Vercel, or any static host.

Main files:

- `index.html`
- `styles.css`
- `assets/`

Demo repository:

https://github.com/Akshad265k/Drishti
